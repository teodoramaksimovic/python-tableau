# Python & Tableau Data Analytics Projects

Data analytics projects combining Python for data cleaning and preprocessing with Tableau for interactive data visualization.

Each project explores a different dataset, focusing on uncovering patterns, extracting meaningful insights, and presenting findings through interactive dashboards.

## Projects

### 1. BlogMe Article Analysis & Sentiment Analysis

Analyzed news article data to explore audience engagement, headline sentiment, and publisher performance.

- Cleaned and processed data using Python and pandas.
- Applied VADER sentiment analysis to classify news headlines.
- Created an interactive Tableau dashboard to visualize engagement trends and sentiment patterns.

📁 [View Project](blogme-article-and-sentiment-analysis)

📊 [Interactive Tableau Dashboard](https://public.tableau.com/app/profile/teodora.maksimovic/viz/BlogMeArticleAnalysisSentimentAnalysis_17945762631820/BlogMeNewsDashboard)

### 2. Blue Bank Loan Analysis

Explored loan portfolio data for a fictional bank to identify patterns in borrower characteristics, interest rates, and credit scores.

- Cleaned and transformed loan data using Python and pandas.
- Analyzed borrower income, FICO scores, and loan characteristics.
- Developed an interactive Tableau dashboard with KPIs, filters, and detailed loan-level insights.

📁 [View Project](blue-bank-loan-analysis)

📊 [Interactive Tableau Dashboard](https://public.tableau.com/app/profile/teodora.maksimovic/viz/BlueBank_17945288744050/BlueBankLoan)

## Technologies Used

- **Python** - pandas, NumPy, matplotlib
- **Sentiment Analysis** - VADER
- **Data Visualization** - Tableau Public
- **Data Analytics** - Data cleaning, exploratory analysis, and dashboard development
